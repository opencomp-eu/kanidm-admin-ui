# Project Rules

- Never commit or push unless explicitly asked.
- Never expose, print, commit, or log secrets from `.env` files.
- Never discard uncommitted user changes.
- Do not manually edit generated files.
- Do not weaken authentication or authorization as a shortcut.
- Ask before making destructive or security-sensitive architectural changes.
- Do not take screenshots for confirming visual changes. Instead you should ask the user to verify.
